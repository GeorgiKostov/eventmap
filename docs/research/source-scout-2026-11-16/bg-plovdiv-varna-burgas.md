# BG source scout: Plovdiv, Varna, Burgas (2026-11-16)

Research only (about 150 light GETs, UA "OkoloScout"). No DB writes. Builds on `docs/research/bg-event-sources.md`.
Terms column = facts + linkback only, never prose/images. All pages are UTF-8 (no Windows-1251 seen).
"Upcoming" counts are what was visible on 2026-11-16.

**Key finding.** No JSON-LD Event, ICS, RSS or JEvents exists on any registered Plovdiv/Varna/Burgas source. Only one registered source has a real API: Palace of Varna (The Events Calendar REST + ICS). The rest are server-rendered HTML with very regular markup, so small bespoke parsers beat the LLM route. Two of the best new sources (koiraboti.com Burgas, FCC Varna) are plain HTML day or list pages.

## Top 5 by events per effort

1. **koiraboti.com Burgas day pages (B1)**: 150–250 events, one tiny parser, covers every Burgas venue including the puppet and drama theatres. Fixes the "Burgas = 0" problem alone. Needs George's nod on terms.
2. **FCC Varna homepage (A, id 1197)**: about 66 events with explicit date, time and venue in one GET. Mostly concerts, some ballet.
3. **Palace of Varna ICS/tribe (A, id 1198) plus vnpuppet.com ICS (B4)**: zero-code, existing `ical` adapter, 14 plus 2 events. The puppet theatre is the only true kids' feed found for Varna.
4. **info.gotoburgas.com list → detail (A, id 1074)**: 83 events, existing two-hop adapter plus a "Дата/Час/Място" label parser, 3 tagged kids/family.
5. **Opera Varna monthly program (B5) and visit.varna.bg list (A)**: about 39 opera/ballet per month and about 100 exhibition/festival items; the list page needs no second hop for dates. (Opera Plovdiv program, id 1079, is the Plovdiv equivalent at about 6 per month.)

**Plovdiv caveat.** The best Plovdiv options are thin: Opera Plovdiv (about 6/month), the 10-item plovdiv.bg culture calendar and the Visit Plovdiv nodes. The city has no JSON-LD/ICS source I could find, and kapana.bg and burgas.bg sit behind Cloudflare. Realistic Plovdiv lift is about 10–25 events per month until the theatre/museum domains are identified (B12/B13).

**Housekeeping.** Registered rows 1162/1082 (oldplovdiv.bg, stale) and any floraburgas.com row should be marked non-working. Per CLAUDE.md rule 7, any new source above must also be reachable via `scripts/crawl.mjs` (not only mined) before it counts as done.
