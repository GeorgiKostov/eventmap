# Sofia deterministic (no-LLM) source scout — 2026-11-16

Research only. All probes used the declared UA (`OkoloBot/1.0 ...`), robots.txt read per host, light GETs only
(no bulk). Counts are rough, taken from the live pages today. Builds on `docs/research/bg-event-sources.md`.

Key finding: three registered-but-LLM-stuck Sofia sources already expose structure that existing adapters
(jsonld / two-hop) can read. The fastest win is **clubcheta.com (2501)**.

## Top 5 by events-per-effort

1. **clubcheta.com (2501)** — ~230 kids occurrences/month, Sofia, 100% family. Everything is already in JSON-LD on detail pages. Only work: two-hop route + parse `EventSeries` occurrences. No ToS found. Highest value by far.
2. **Столичен куклен театър (2503)** — ~35 family shows/month, perfectly regular cp1251 HTML. One small bespoke parser; robots explicitly permits search/reference.
3. **Around You BG city=8** — 97 Sofia events (concerts, plus a kids tag). WP REST for the list and JSON-LD for dates (nested `mainEntity`). Gives broad adult/evening coverage Sofia lacks; copyright clause is generic, flag it.
4. **Софийска филхармония (2354)** — ~25/month, clean `MusicEvent` JSON-LD, already `works`; just move off the LLM route and fix the fake-`Z` timestamp.
5. **Топлоцентрала** — microdata Event, existing adapter, ~10-20 events; trivial to register. (Народен театър, ~38/month, is the next one up if more volume is wanted: bespoke HTML parser.)

Needs George's call before anything else: **сДетето (sdeteto.com)** and **sofia.plays.bg** are the richest kids sources (150+ and ~100+ cards, sdeteto has full Event JSON-LD) but both ToS texts forbid copying any part of the site without written consent. Worth one permission email each (they are small family-tech businesses and gain traffic from linkback).

## Notes for adapter authors

- Sofia is Europe/Sofia wall-clock; clubcheta/sdeteto give `+02:00` offsets (winter). Philharmonic's `...000Z` is local time mislabelled, so ignore the zone.
- sdeteto's JSON-LD has a corrupt `@context` key; parse by `@type`, not by context.
- sofiapuppet.com is Windows-1251 (decode before regex); month URLs `programa.php?year=YYYY&month=M`.
- WordPress hosts here do NOT run The Events Calendar (`/wp-json/tribe/events/v1/events` 404) except lozenets (1 event); do not expect tribe routes in Sofia.
