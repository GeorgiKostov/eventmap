## Destination

https://www.okolo.events/?lat=48.3069&lng=14.2858&when=all&utm_source=facebook&utm_medium=paid_social&utm_campaign=linz_advent_2026&utm_content=market_illustration

The existing app supports the supplied Linz coordinates and `when=all`, so incoming readers are not restricted to today's events. It does **not** currently support a seasonal-filter URL parameter: readers select “Weihnachtsmärkte” in the filters. This is an honest usable destination; a future direct Christmas-filter link would remove that extra tap.

Before the run, check this link on a phone, select Weihnachtsmärkte, and confirm upcoming Linz markets still have accurate dates. Do not silently add a nonexistent theme parameter.

## After the test

If people visit and explore events, consider a second small test before the first Advent weekend, using the same audience and a refreshed opening-weekend message. Approve its budget separately. Stop the seasonal campaign at its scheduled end; do not leave Christmas messaging running after the season.
